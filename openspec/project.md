# CodeLore

Ambient codebase tips for AI-assisted developers working in the terminal (Claude Code, Grok, and friends).

**Problem:** AI multiplies code velocity faster than human context absorption. Tribal knowledge dies in chat logs.

**Product:** Ranked, repo-aware lore dripped at session boundaries via terminal and macOS Notification Center.

**Stack (MVP):** TypeScript CLI, YAML tip packs in `.codelore/`, local seen-state, Claude Code SessionStart hooks.
